## Overview

ANA 2 is a full-featured synthesizer from Sonic Academy tailored for electronic dance music, with triple-oscillator architecture, 8 FX slots, an arpeggiator, and over 1,200 factory presets.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonic Academy ANA** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Triple Oscillator** | Three independent oscillators with 1024-frame wavetable banks |
| **8 FX Slots** | Insert chain of compression, EQ, distortion, reverb, and delay |
| **Arp and Chord** | 32-step arpeggiator with chord trigger and strum controls |
| **Macro Controls** | Eight knob macros each mappable to multiple parameters for live control |
